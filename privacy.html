นโยบายความเป็นส่วนตัว

มีผลตั้งแต่วันที่ 27 สิงหาคม 2026

หลักของ AutoPost RV คือข้อมูลเนื้อหางานของลูกค้าเก็บอยู่ในเครื่องลูกค้า ข้อมูลที่ส่งไปยังระบบของเราจำกัดเท่าที่จำเป็นสำหรับบัญชีผู้ใช้ เครดิต และการผูกโปรไฟล์เท่านั้น

1. ข้อมูลที่เก็บไว้ในเครื่องของผู้ใช้

รายการกลุ่ม ร่างข้อความ รูป วิดีโอ ประวัติและลิงก์โพสต์จริง รวมถึง Chrome/Facebook session ถูกเก็บในโฟลเดอร์ข้อมูลของโปรแกรมบนเครื่องผู้ใช้ ระบบของเราไม่อัปโหลดเนื้อหาเหล่านี้ไปยัง backend เพื่อใช้งานตามปกติ

2. ข้อมูลที่ระบบออนไลน์ได้รับ

  • รหัสบัญชีผู้ใช้และอีเมลจากการเข้าสู่ระบบ
  • รหัส Facebook แบบตัวเลขและรหัสโปรไฟล์ภายในเครื่อง เพื่อแยกบัญชีและป้องกันการผูกบัญชีซ้ำ
  • รายการอนุมัติใช้เครดิต สถานะผลลัพธ์ และยอดเครดิตคงเหลือ โดยไม่ส่ง URL กลุ่ม ชื่อกลุ่ม ข้อความ รูป หรือวิดีโอ
  • ชื่อแสดงผลหรือ LINE ID เฉพาะเมื่อผู้ใช้เลือกกรอกข้อมูลดังกล่าว

3. วัตถุประสงค์

เราใช้ข้อมูลเพื่อยืนยันตัวตน จัดการสิทธิ์ทดลองและแพ็กเกจ ป้องกันการใช้บัญชีซ้ำ ให้บริการสนับสนุน และรักษาความปลอดภัยของระบบเท่านั้น

4. ผู้ให้บริการที่เกี่ยวข้อง

ระบบบัญชีและเครดิตใช้ Supabase ผู้ใช้อาจเลือกเข้าสู่ระบบผ่าน Google ดาวน์โหลดโปรแกรมจาก GitHub Releases และติดต่อเราผ่าน LINE เมื่อกดลิงก์ออกจากเว็บไซต์ บริการเหล่านี้มีนโยบายความเป็นส่วนตัวของตนเอง

5. การควบคุมและการลบข้อมูล

ผู้ใช้สามารถเปิดโฟลเดอร์ข้อมูล สำรอง หรือลบข้อมูลภายในเครื่องได้จากโปรแกรม หากต้องการขอแก้ไขหรือลบบัญชีและข้อมูลบน backend ให้ติดต่อทีมงานผ่าน LINE Official

6. การเปลี่ยนแปลงนโยบาย

หากการเก็บหรือใช้ข้อมูลเปลี่ยนแปลงอย่างมีนัยสำคัญ เราจะปรับปรุงหน้านี้และวันที่มีผลก่อนนำการเปลี่ยนแปลงไปใช้กับลูกค้า
